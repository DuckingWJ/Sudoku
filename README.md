# Sudoku 项目说明

## 项目简介
这是一个基于 Python 的数独求解与校验项目，包含：
1. 核心求解引擎（深度优先搜索 + 约束剪枝）
2. 图形化交互界面（可手动填数、自动求解、合法性检查）

用户可以在界面中输入任意数独局面：
1. 若未填满，系统会自动给出求解结果  
2. 若已填满，系统会检查该结果是否合法

---

## 核心搜索算法与剪枝策略

### 1. 搜索框架：DFS 回溯
求解核心采用深度优先搜索（DFS）回溯：
1. 在空白格中选择一个位置
2. 尝试填入数字 1 到 9
3. 若当前填法不冲突则继续递归
4. 若后续无解则撤销本次填入（回溯）

当剩余空格数为 0 时，表示找到完整解，立即返回成功并结束搜索。

### 2. 状态表示
为了高效判断可行性，维护三组布尔约束表：
1. row_mp[r][v]：第 r 行是否已使用数字 v  
2. col_mp[c][v]：第 c 列是否已使用数字 v  
3. grid_mp[g][v]：第 g 个 3x3 宫是否已使用数字 v  

这样可在 O(1) 时间判断一个数字能否放入某个格子。

### 3. 剪枝策略
项目中使用了多层剪枝来减少搜索分支：

1. 约束合法性剪枝  
放置前先检查行、列、宫是否冲突；冲突则直接跳过该数字。

2. 选点启发式剪枝  
优先选择“约束最强”的空格进行尝试（相关行/列/宫已使用数字越多，越优先），尽早触发失败分支并回溯。

3. 提前终止  
一旦找到可行完整解，立即返回，不再继续遍历其它分支。

### 4. 完整性校验
对于已填满棋盘，使用校验函数进行最终验证：
1. 每行必须包含 1 到 9
2. 每列必须包含 1 到 9
3. 每个 3x3 宫必须包含 1 到 9

只有三者都满足时，才判定为合法数独解。

## 交互式界面实现

### 1. 技术方案
GUI 使用 tkinter 实现，构建 9x9 输入网格和操作按钮。

### 2. 主要交互功能
1. 单元格输入限制  
每个格子仅允许输入 1 到 9 或留空，非法输入会被拦截并清理。

2. 实时冲突标记  
处理前会检查当前棋盘冲突，冲突格会高亮提示，避免无效求解。

3. 一键处理逻辑  
点击 Process 后：
1. 若棋盘已填满：执行合法性校验并弹窗显示结果  
2. 若棋盘未填满：执行求解并将结果回填到界面

4. 清空重置  
点击 Clear 可清空全部输入并恢复默认显示状态。

### 3. 运行方式
在项目目录执行：
```bash
python gui.py
```

## 总结
该项目实现了“可交互输入 + 自动求解 + 完成校验”的完整闭环。  
核心通过 DFS 回溯配合约束剪枝，在保证正确性的同时显著提升了求解效率，适合作为数独求解与搜索算法实践项目。
